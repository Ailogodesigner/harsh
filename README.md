# ADITYA KASHYAP — FULL-STACK DEVELOPER PORTFOLIO

High-velocity, interactive developer portfolio engineered with **Next.js 16 (App Router)**, **React 19**, **Tailwind CSS v4**, **Framer Motion**, and hardware-accelerated 3D components.

---

## ⚡ Key Highlights & Architecture

- **Bespoke Cyberpunk Palette**: Midnight Obsidian (`#04030a`), Electric Ultraviolet (`#a855f7`), and Acid Lime (`#a3e635`).
- **Interactive Hero Terminal**: Emulated bash shell supporting `whoami`, `skills`, `projects`, `contact`, `hire`, and `clear`.
- **Fey.com 3D MacBook Scroll**: Hardware-accelerated perspective viewport opening the MacBook lid smoothly on scroll without blocking content.
- **Aceternity UI & Skiper UI Integrations**:
  - `3d-card`: 3D perspective hover cards with translateZ depth.
  - `background-lines`: Animated curved SVG gradient lines.
  - `container-text-flip`: Kinetic word rotator with smooth spring physics.
  - `focus-cards`: Focus hover matrix with dynamic sibling blur.
  - `expandable-cards`: Fullscreen architectural modal inspector.
  - `Skiper52`: Responsive multi-panel horizontal expander accordion.
- **Offline-Ready SVG Assets**: Zero external CDN dependency; all icons and illustrations render locally from `/public/images/`.
- **Self-Contained Architecture Inspection**: All project actions inspect architecture directly on-site.
- **Test-Driven Verification**: 100% passing test suite running on Vitest.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 16 (App Router + Turbopack)
- **Runtime**: Node.js 22 LTS / Cloudflare Workers
- **Styling**: Tailwind CSS v4 + Framer Motion
- **Testing**: Vitest 5.x
- **Icons**: Lucide React
